# Quality Assessment: Nameless Quest

**Date:** Feb 6, 2026 | **Version:** 0.6.13 | **Assessed by:** Sophie  
**Grade:** ⚠️ **CLOSE** — Functionally ship-ready, but test infrastructure missing and dependency debt present

---

## Executive Summary

Nameless Quest is a **working, polished Vue 3 application** that successfully builds, deploys, and runs. The codebase demonstrates solid architectural patterns, clean code, and good DevOps practices. **However, it lacks test coverage entirely—zero automated tests—and carries significant dependency debt that will eventually force a migration.**

**Ship Status:** Can deploy to production today, but risks are manageable only for a **low-traffic, non-mission-critical app**. For growth, invest in tests before adding major features.

## ✗ What's Broken or Missing

### 1. **Zero Test Coverage** (CRITICAL RISK)

- **Finding:** 0 test files (no `.test.ts`, `.spec.ts`, vitest/jest config)
- **Risk level:** HIGH for production
  - No regression detection if refactoring
  - Firebase integration untested (auth, Firestore CRUD)
  - Component rendering paths unknown (hover states, state transitions)
  - Edge cases in hex/toss binary conversion untested
  - Passwordless auth flow (magic links) not validated automatically
- **Impact:** Any change to core Oracle logic, auth, or journal is manually verified only
- **Blocker for scale:** Adding tests now is overhead; better to add before features grow
- **Recommendation:**
  - Minimum viable: Unit tests for `utils/tosses.ts` (binary conversion), `store/rolls.ts` (CRUD)
  - Medium priority: Component tests for Oracle, LoginEmail, OracleResponse
  - Later: E2E tests for full auth flow

### 2. **Firebase v9 End-of-Life Risk** (MEDIUM TERM)

- **Issue:** Firebase SDK v9 is legacy; v12.9.0 is current
- **Urgency:** Not immediate, but v9 support expires ~2026
- **Migration effort:** Moderate (syntax already modular; refactor imports + API calls)
- **SYSTEMS-AUDIT.md** covers this well; plan roadmap within 6–12 months

### 3. **Vite 2 → 7 Major Gap** (MEDIUM TERM)

- **Current:** Vite 2.9.18 (from 2021)
- **Latest:** 7.3.1 (2025)
- **Risk:** Not critical today, but 5 major versions skipped
- **Why it matters:** Build config syntax changed, plugins refactored, HMR behavior differs
- **Recommendation:** Plan incremental upgrade path (v2 → v4 → v7) before January 2027

### 4. **Passwordless Auth Incomplete** (KNOWN ISSUE)

- **Status:** Documented in `docs/passwordless.md`
- **Problem:** Magic email links work, but route guard has race condition
  - User clicks email link → lands in `/login` instead of `/journal`
  - Root cause: `cachedUser` not loaded before guard runs
- **Current workaround:** Unclear; may be bypassed in practice
- **Fix:** Use Firebase `onAuthStateChanged()` to wait for auth state before routing
- **Severity:** Medium (login workflow degraded but not broken)

### 5. **Journal Refresh Race Condition** (MINOR)

- **Issue:** Comment in `src/store/rolls.ts`: "TODO: How can we refresh the journal entries after delete?"
- **Current:** Delete works, but UI may not auto-refresh
- **Fix:** Call `getRolls()` after delete (actually already in code; TODO may be outdated)
- **Severity:** Low (minor UX polish)

## Conclusion

**Nameless Quest is a well-built, aesthetically pleasing I Ching oracle application.** The Vue 3 codebase is clean, the build pipeline is solid, and deployment is ready. The fatal gap is **test coverage: zero tests for a stateful application with Firebase integration is a risk.**

For a **personal project or hobby app**, this is fine—ship it. But for a **growing product with users**, add tests before the next major feature. The good news: the code is well-structured, making tests easy to add retroactively.

**Final grade:** ⚠️ **CLOSE — functionally ready, structurally sound, testing required for growth.**
